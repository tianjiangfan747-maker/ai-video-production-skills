# Creative Methods — lightweight reference

这份参考用于在用户要求“想创意”但没有明确方法时，帮助 AI 选择合适的发散方式。

## 默认顺序

1. 先找事实/洞察/张力
2. 定义传播命题
3. 用 2–3 种明显不同的创意机制发散
4. 用目标、受众、品牌/文化关联、记忆度、可执行性筛选
5. 推荐 1 条主线并给出备选

## 可选方法

- SCAMPER：已有产品或文化内容需要快速变体时
- TRIZ / contradiction thinking：目标之间存在明显矛盾时
- Forced connection / bisociation：需要跨领域的意外连接时
- Morphological analysis：概念空间很大，需要系统探索时
- Human truth / tension framing：广告或品牌叙事缺少“为什么在意”时

方法不是目的。一次任务只选择最合适的 1–2 个方法，避免方法堆砌。
