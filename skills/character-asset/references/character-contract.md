# Character Contract

## Identity anchors

优先选可观察、可比较、跨角度稳定的锚点，不追求把整个脸写成百科全书。

## Reference board QC

1. 四面板属于同一角色。
2. Panel 2 无头且不具伤口语义。
3. 服装层级、鞋、关键配件稳定。
4. 侧/背面支持体积判断。
5. reference image ID、版本、状态可追踪。

## Panel 2 回退方案

无头身体格（Panel 2）是本项目的自定义设计，用于把身体/服装控制与身份分离。若下游模型因此出现身份漂移或断头语义，回退为完整正面全身，把“身份/身体分离”改到多参考图槽位层面实现（一张锁身份、一张锁身体服装），并把实测结论记回合同。
