# Midjourney 风格资产工作流（按需预备）

## 用途

当项目首先需要鲜明的美学方向、风格化场景或资产母版时，使用 Midjourney 做风格探索。它不是所有图像任务的默认前置步骤，也不代替角色身份、服装结构或空间几何控制。

## 最短流程

`探索方向 → 选定 Style Master → 记录风格合同 → 分离身份/空间控制 → 交接视频关键帧`

### 1. 探索方向

- 先固定一个简单主体或场景，让不同试验主要改变风格，而非同时改变人物、镜头、道具和光线。
- 少量生成、按项目目标筛选，不追求风格词数量。
- 选中后保留原图、生成设置和所用参考的来源，方便复现。

### 2. Style Master 与风格合同

Style Master 是后续资产的风格基准，不一定是构图或角色身份基准。记录以下维度即可：

| 维度 | 记录内容 |
|---|---|
| 媒介与表面 | 摄影/插画/定格等，颗粒、笔触、边缘处理 |
| 色彩 | 主色、辅色、饱和度、明暗关系 |
| 造型 | 比例、轮廓、几何/有机倾向、尺度规则 |
| 材质 | 关键材质及其粗糙度、透明度、反射特征 |
| 光影 | 主光位置、软硬、色温、阴影与必要的环境光来源 |
| 场景处理 | 前中后景、留白/密度、背景抽象程度 |

只记录真正需要跨资产保持的项目。将风格合同交给角色/场景资产与 `style-quality-boost`，不要把探索期全部形容词附到每条视频 Prompt。

### 3. 三种参考不要混用

- **风格参考 / Moodboard**：负责美学、色彩、材质、氛围；不承担身份锁。
- **主体参考**：负责角色、产品、道具等“是什么”；使用当前版本实际支持的对应参考功能。
- **构图 / 空间参考**：负责机位、比例、位置、前中后景和出入口；必要时回到 Spatial Master / Blockout。

一张参考图可能含有多种信息，但工作流中必须声明“这张图这次只控制什么”。发现风格参考把主体或构图带偏时，减少冲突信息或分开阶段，而不是继续堆权重。

### 4. 光影作为可选控制层

需要时补充：`光源位置 → 方向 → 软硬/色温 → 亮暗比 → 遮挡与投影 → 材质响应`。跨镜记录光源连续性与允许的变化。动态光影要有门、窗、灯、人物运动等原因，不添加无来源的装饰扫光。

### 5. 向视频交接

1. `Style Master + 风格合同` → `style-quality-boost`。
2. `主体参考 + 必要身份锚点` → `character-asset` / `prop-asset`。
3. `空间母版 + 光源/出入口` → `scene-asset`。
4. 定好的关键帧与镜头卡 → `storyboard-director` → `shot-execution`。

强关键帧已经提供身份、构图、材质时，视频 Prompt 主要写运动、遮挡、光影变化和结束态；不重复静态资产描述。

## 版本边界

MJ 的模型版本、参考功能、参数名称、权重范围和组合兼容性可能变化。只使用当前账号与官方界面/文档实际支持的组合，项目记录实际设置；不要在 Skill 中固化未经验证的版本参数，也不要把第三方模型对比截图当成永久排名。
