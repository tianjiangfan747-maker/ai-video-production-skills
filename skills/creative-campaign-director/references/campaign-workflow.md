# Campaign Workflow

## Creative Core

Brief → Audience → Insight/Tension → Proposition → Creative Route → Big Idea → Story → Visual System

## Production Core

Key Assets → Storyboard → Shot List → Keyframes → I2V/T2V prompts → Takes → QC → Edit → Master → Cutdowns
