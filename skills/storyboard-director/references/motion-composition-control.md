# 极简动作构图控制图

## 目标

把图片抽象成低信息干扰的视觉参考，只控制本次制作真正需要的信息。控制图不是固定的景深模板，也不要求每张图都包含环境、透视或前中后景。

用户说“控制图”“动作参考图”“构图参考图”“抽象参考图”“简单线条参考”“补镜垫图”时使用本流程。每个镜头输出一条可独立复制的图生图提示词；用户要求实际生成图片时，再调用图像工具。

## 先选用途

| 用途 | 默认保留 | 默认删除 |
|---|---|---|
| 动作与机位控制 | 姿势、重心、朝向、机位、主体位置与占比、关键道具 | 无关环境和景深 |
| 空间与层次控制 | 上述信息，以及必要的透视、前中后景、出入口、遮挡和尺度 | 不参与构图的背景细节 |
| 补镜／补视频垫图 | 能衔接前后镜的起始或关键姿势、运动方向、构图和道具关系 | 会污染生成结果的身份、材质、文字和杂乱环境 |
| 外部图片构图提取 | 站位、机位、主体比例、构图形状、运动方向、冲击轴线与关键物体 | 原图人物身份、服装、品牌、风格、文字、水印和无关元素 |

外部图片可以来自用户上传或其合法取得的其他素材。只抽象构图和动作结构，不复制原图角色身份、作品风格或可识别品牌元素。

## 按需控制，不多控

默认只保留 2—5 项关键关系。先问“删掉这项会不会影响这次使用”，不会就删除。不要因为是室内就自动加透视，也不要因为是室外就自动加地平线或建筑。

### 启用景深的情况

只有层次本身影响构图、调度、撞击方向、出入口、主体尺度或前后遮挡时才保留：

- 室内用少量墙面、地面和通道的汇聚线，配合近大远小与必要出口组织空间。
- 室外用地平线、道路或少量环境轮廓交代必要距离。
- 远景只用更短、更疏的概括线，不靠灰度、阴影或虚化制造景深。

### 关闭景深的情况

只关心人物动作、姿势、机位或道具关系，或者室外环境会带来干扰时，背景可以全部删除，最多保留一条必要地面线或接触线。高空画面也不强制添加建筑和地面；产品图只在尺度参照有必要时保留环境。

## 线条合同

- 使用纯白背景和极少量统一线宽的灰色简单线条。
- 不使用色块、实心填充、灰底、排线、阴影、渐变或写实虚化。
- 不画精细线稿；角色只保留头、躯干、四肢和必要尾部等概括外轮廓，道具只保留识别所需的基本几何形。
- 火焰、雨、砂尘等只在影响动作或方向时保留极少量稀疏方向线，不画粒子纹理。
- 不添加箭头、机位图标、标注或说明文字，除非用户明确要求。

## 补镜与补视频

控制图可作为缺少关键帧时的干净参考，用来先生成过渡帧、补充镜头或直接辅助视频生成。只借它的动作、机位和构图，不要求最终画面继承控制图的视觉形式。

交给视频阶段时必须同时明确：角色与产品外观以正式资产为准，场景以对应场景资产为准，控制图仅提供指定的结构信息；最终视频不得出现白底、灰色线条、抽象人形或控制图本身。

## 通用提示词模板

```text
将 @输入图片 转换为 [画幅] 的极简[动作／构图／空间]参考图，用于[动作控制／补镜垫图／构图提取]。

只使用纯白色背景和极少量统一线宽的灰色简单线条，不使用任何色块或实心填充。

用极少线条保留[主体位置与占比]、[关键姿势与接触点]、[机位与运动方向]和[关键道具]。
[需要景深时：用少量汇聚透视线、近大远小和前后遮挡保留必要空间关系。]
[不需要景深时：删除全部无关背景，只保留主体和必要接触线。]

不要人物身份、服装或机械细节、原图风格、精细线稿、材质、阴影、渐变、色块、箭头、文字、Logo 或水印。
```

按当前用途只保留一个方括号分支，其余括号全部替换或删除。能少一条线就少一条，但不能删掉本次使用必需的信息。

## 视频阶段附加约束

```text
@控制图 仅用于参考[动作／机位／构图／指定空间关系]，角色与产品外观以正式资产为准，场景以对应场景资产为准。不要继承控制图的白底、灰线、抽象人形或任何示意图风格。
```

## 验收

- 一眼能读出本次真正需要控制的信息，没有为了“完整”而增加无关线条。
- 未启用景深时没有多余环境；启用时透视汇聚一致、近大远小合理。
- 补镜参考能衔接前后镜，外部图片只转移结构，不带来原图身份和风格。
- 没有色块、精细线稿、材质光影或文字污染，也没有擅自改变需要保留的动作、比例、位置和构图。
