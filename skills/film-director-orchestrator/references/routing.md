# Routing Cheatsheet

| 用户需求 | 负责 Skill | 主要输出 |
|---|---|---|
| 创建角色 | character-asset | identity contract + reference board plan |
| 创建场景 | scene-asset | spatial contract + reference plan + clean plate |
| 创建道具 | prop-asset | prop contract + state variants |
| 这场戏怎么拍 | storyboard-director | beat map + blocking + shot cards + handoff |
| 这个镜头怎么生成 | shot-execution | neutral shot prompt |
| 生图结构不稳 | image-control-pass | shortest control chain |
| 视频生成失败 | video-production-qc | diagnosis + cheapest fix |
| 多镜头剪辑 | edit-assembly | edit boundary + timeline plan |
| 广告/宣传片/文化推广 | creative-campaign-director | 创意方向 + 传播方案 + 制作计划 |
