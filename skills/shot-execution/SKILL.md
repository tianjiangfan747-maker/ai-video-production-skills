# Shot Execution

## 1. Image says what; Prompt says what happens

强参考图已经提供身份、构图、空间与视觉语言时，不重复描述。当前镜头的文字只负责变化。

Runway 当前 I2V 指南也建议主要描述 motion，并从简单 Prompt 开始、一次增加一个变量。

## 2. 内部六层

1. 起始状态 / 因果
2. 一个主行动
3. 空间方向 / motion vector
4. 一个主摄影机行为
5. 必要环境运动 / 声音
6. 结束状态

## 3. 自然表演

心理因果用于内部驱动；最终描述优先落到可观察动作。

允许停顿、犹豫、自然重心变化、反应先后。除非微动作本身传递剧情信息，不要列眉毛、鼻翼、瞳孔、喉结、手指等肌肉清单。

## 4. 空间先于修辞

双人/多人、打斗、追逐、飞行、投掷或画外目标出现时必须有参照系：screen-left/right、foreground/background、axis、camera side、eyeline、motion vector、entry/exit、action start/end。

## 5. Motion Budget

默认：**一个主动作 + 一个主摄影机行为 + 最多一个重要环境运动**。

超预算不是绝对错误，但要有原因；复杂链条优先拆镜。

## 6. 摄影机

回答：从哪里看、为什么从这里看、最后停在哪里。必要时写 `start → trigger → path → endpoint`。

## 7. 结束态

每镜必须说明人物、物体、视线和摄影机最终停在哪里，以及下一镜从什么东西接上。

## 8. 平台中性输出

先输出 neutral shot prompt，再交给平台适配层。这样同一导演决定可以映射到多个模型。

## 9. 镜头包裹动作（按需）

“包裹”是摄影机与动作、场景层次的统一调度，不是堆砌运镜名词，也不是必须环绕一周。需要空间冲击、遮挡揭示或尺度变化时，用一条可读链表达：

`起始构图 → 主动作/触发 → 摄影机路径 → 前景遮挡或层次揭示 → 结束构图`

- 摄影机路径与主体运动方向、速度相互配合；仍遵守 Motion Budget，一个主要镜头行为可以包含起点、终点和短暂遮挡。
- 只写影响画面的前/中/后景关系：谁遮住谁、何时露出什么、尺度如何改变。无叙事作用的遮挡不添加。
- 环绕、穿越前景、跟随、低机位揭示都是可选手段；先服务叙事，再选最简路径。
- 光影变化若参与揭示，写清来源和原因，例如人物经过门洞时窗光扫过脸；不要另加无来源的扫光。

例：人物沿画面右侧走向窗边，镜头贴近右肩跟随；门框短暂遮住人物，经过后露出远处高塔；人物在窗前停步，镜头停在越肩中景。

## 10. 最终压缩与语义审查

Prompt 不是字段大拼盘。优先保留：动作、方向、摄影机、时序、结束态。只有参考图没有提供或本镜需要改变的视觉信息才补写。

输出前依次检查：

1. **必要性**：每一项是否改变本镜的动作、构图、光影、材质、节奏或结束态？不影响就删。
2. **覆盖关系**：强参考图已经锁定的身份、服装、构图、空间、材质不重复；正面语义已覆盖的否定不再写。
3. **限制词**：用户明确要求的排除项保留，例如无字幕、无 BGM、无乱码/杂乱线条；已知失败风险可保留一条针对性约束。不要默认附加通用 `no watermark, no logo` 尾巴。
4. **重复与冲突**：合并同义形容词和重复资产描述；多个互相竞争的运镜优先拆镜或只留主路径。
5. **调度精度**：省词不能省掉运动方向、遮挡关系、节奏触发、光线来源和结束态。

不以机械字数判定好坏；短而含糊仍需补关键关系，长但每句都有独立作用不必强删。合集根目录的 `scripts/review_prompt.py` 可辅助发现否定词密度、重复片段、竞争运镜和质量标签堆叠；它只是提醒，最终删改必须由上述语义审查决定。
