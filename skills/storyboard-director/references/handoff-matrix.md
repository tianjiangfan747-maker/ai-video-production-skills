Handoff 优先级：动作 → 视线 → 屏幕方向 → 空间入口 → 构图 → 遮挡 → 道具 → 光线 → 声音。

不是每个镜头都需要所有类型；但相邻镜头必须至少有一个可感知的接力点。

平台支持首尾帧时，上一镜末帧可以直接作为下一镜首帧（尾帧接力），这是最稳定的物理接力；不支持时按上表优先级用动作/视线/方向/遮挡/声音完成接力。
